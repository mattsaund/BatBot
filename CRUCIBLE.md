A local AI engine that allows a model to work on a project circularly over a long period of time improving on the project. These models loaded into Crucible will have tool access like claude where it  can code, run projects, and connect to the internet. 

When you put a prompt in you can set a time for how long you want it to "Cook" or you can have it work until you stop it. When stopped it does the finishing touches to get the project working.

The output text will show what its currently working on and changing so you can see it improve the project and its thought process in the output window. 

For formulating responses you can see the in depth response get curated in real time. It can also ask questions while its cooking to better improve the project.
